Are the re-used answers right?

A high hit rate only helps if the re-used answers are correct. For a share of similar-question matches the companion asks the model the same question again, skipping the cache, and compares the two answers.

Checked before serving

When a saved answer is a close call between look-alike questions, the companion asks the model first and only serves the saved answer if the model agrees, like checking the label before handing over the parcel.
